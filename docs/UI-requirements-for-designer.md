# BabyFood 交互页面功能 UI 要求（设计师原型用）

> 基于当前 Android 应用实现整理，供设计师输出高保真/交互原型使用。  
> 技术栈：Material Design 3、Jetpack Compose、底部 Tab + 页面内导航。

---

## 一、全局框架

### 1.1 主壳（登录后）

- **布局**：顶部 Header + 内容区 + 底部导航栏；**无页面级标题栏、无返回按钮**（更多内容空间）。
- **顶部 Header（AvocadoHeader）**
  - 左侧：品牌文案 "GROW HEALTHY" + 当前宝宝名称 + 月龄（如 "小明 (12个月)"）；可配宝宝头像占位。
  - 右侧：通知图标按钮。
  - 仅在主 Tab 页显示（首页、食谱、计划、仓库、宝宝）；子页不显示。
- **底部导航栏（AvocadoBottomBar）**
  - 5 个 Tab：首页(Home)、食谱(Recipes)、**中间悬浮扫描(SCAN)**、计划(Growth)、宝宝(Profile)。
  - 中间为圆形悬浮按钮（相机/扫描），突出显示。
  - 当前 Tab 高亮（主色 + 粗体）。
- **页面切换**：Tab 间有淡入 + 水平滑动过渡动画。

### 1.2 子页通用

- 无全局 Header 时，需提供**返回入口**（由各子页自行实现，如 TopAppBar 返回或从 MainScreen 传入的 onBack）。
- 多数列表/表单页使用 **AppScaffold**：无顶栏，内容区 + 底部浮动操作按钮（如「添加」「编辑」）。

## 二、认证与法律

### 2.1 登录页（LoginScreen）

- **功能**：手机号或邮箱 + 密码登录；支持跳转注册、忘记密码（占位）。
- **UI**
  - 居中布局：品牌 Logo、应用名 "BabyFood"、副标题「智能餐单推荐 · 科学营养搭配」。
  - 表单：账号输入框（手机号或邮箱）、密码输入框（支持显示/隐藏密码）、登录按钮。
  - 登录中：按钮显示 loading，禁用返回键。
  - 底部：「注册账号」链接。
- **状态**：加载中、账号/密码错误提示（Snackbar 或 ErrorDialog）。

### 2.2 注册页（RegisterScreen）

- **功能**：手机号/邮箱 + 验证码 + 密码注册；可查看服务条款、隐私政策。
- **UI**：表单（账号、验证码+发送按钮、密码、确认密码）、注册按钮、返回登录、法律文案链接（服务条款、隐私政策）。

### 2.3 服务条款 / 隐私政策（TermsOfServiceScreen / PrivacyPolicyScreen）

- **功能**：纯阅读页，可返回、可「同意」关闭。
- **UI**：长文滚动、顶部返回、底部同意按钮（按需）。

## 三、首页（今日餐单）

### 3.1 今日餐单页（TodayMenuScreen）

- **功能**
  - 展示当前选中宝宝的**今日营养目标**（可编辑）；今日早/午/晚/点心**餐单时间轴**；**未来一周计划**可折叠。
  - 每餐：换一换（AI 推荐）、选择食谱、查看食谱详情、修改用餐时间、填写进食反馈。
- **布局**
  - 单列垂直滚动。
  - 顶部：**营养目标卡片**（热量/蛋白质/钙/铁进度或数值，可点编辑）。
  - 标题「今日餐单」+ **餐单时间轴**（MealTimeline）。
- **餐段时间轴**
  - 每餐一卡片：左侧时间/圆点，右侧餐段名称（早/午/晚/点心）、食谱名称（或无）、操作：换一换、选食谱、看详情、改时间、反馈。
  - 无食谱时卡片为「空状态」样式（浅底+边框），引导选食谱。
- **未来一周计划**
  - 可展开/折叠的「本周计划」区块（WeeklyPlansSection）。
- **弹窗**
  - **食谱选择对话框**：列表选一道菜替换该餐。
  - **用餐时间选择器**：选择该餐时间。
  - **营养目标编辑对话框**：修改热量/蛋白质/钙/铁，可一键「推荐」按月龄。
  - **进食反馈对话框**：选项（吃完/吃一半/不爱吃/过敏等），过敏时可勾选具体食材。

- **空状态**：未添加宝宝时，显示「还没有添加宝宝信息」+ 引导去宝宝页。

## 四、宝宝模块

### 4.1 宝宝列表（BabyListScreen）

- **功能**：展示宝宝列表；点击进入详情；可设当前宝宝；添加宝宝。
- **UI**：卡片列表（头像/名称/月龄等），当前选中的宝宝卡片有视觉强调（如边框）；底部 FAB「添加」。
- **空状态**：「还没有添加宝宝信息」+ 引导点击添加。

### 4.2 宝宝详情（BabyDetailScreen）

- **功能**：查看/编辑基本信息；生长曲线入口；营养目标编辑；过敏/偏好管理；体检记录入口；生成营养推荐。
- **UI**（从上到下，可滚动）：
  - **用户信息卡片**：头像、姓名、月龄、生日。
  - **生长曲线卡片**：标题「生长曲线」、发育状态标签、最近身高/体重、最后测量日期、「查看详情」跳转生长曲线页。
  - **营养目标卡片**：热量/蛋白质/钙/铁数值，可点击编辑。
  - **过敏食材**：列表 +「管理」进入过敏管理。
  - **偏好食材**：列表 +「管理」进入偏好管理。
  - 底部操作：「编辑」打开宝宝表单；体检记录、生长曲线为文字/按钮入口。
- **状态**：无体检记录时生长区域显示「暂无体检记录」。

### 4.3 宝宝表单（BabyFormScreen）

- **功能**：新增/编辑宝宝（姓名、生日、头像等）。
- **UI**：表单字段 + 提交/取消；底部「保存」或通过 AppScaffold 的 FAB 保存。

### 4.4 过敏食材管理（AllergyManagementScreen）

- **功能**：列表展示过敏项（可含有效期）；添加/删除/编辑。
- **UI**：列表 + 添加按钮；每项可展示过期状态。

### 4.5 偏好食材管理（PreferenceManagementScreen）

- **功能**：同过敏管理，管理偏好食材列表与有效期。
- **UI**：与过敏管理类似，列表 + 添加/编辑/删除。

## 五、计划模块

### 5.1 计划列表（PlanListScreen）

- **功能**：按宝宝查看；日历选日期；查看某日计划列表；进入计划详情；手动添加计划；AI 推荐（选日期范围后生成并进推荐编辑器）。
- **UI**
  - **宝宝选择器**：多宝宝时显示下拉（ExposedDropdownMenu）选当前宝宝。
  - **日历视图**：月视图，上一月/下一月切换，点击日期选中。
  - **选中日期的计划列表**：卡片列表，每项显示餐段、食谱名等，可点击进详情、可「换食谱」打开食谱选择弹窗。
  - 底部两个 FAB：「手动添加」「AI推荐」。
- **弹窗**：日期范围选择（DateRangePickerDialog）、食谱选择（RecipeSelectorDialog）、AI 生成中 loading、错误提示。

### 5.2 计划详情（PlanDetailScreen）

- **功能**：查看某条计划详情、营养汇总等；进入编辑。
- **UI**：信息卡片（日期、宝宝、餐段、食谱等）、营养信息、编辑入口。

### 5.3 计划表单（PlanFormScreen）

- **功能**：手动新建/编辑单条计划（选择宝宝、日期、餐段、食谱等）；可跳转 AI 推荐编辑器。
- **UI**：表单（宝宝、日期、餐段、食谱等）+ 保存/返回；有入口跳转「AI 推荐编辑器」。

### 5.4 AI 推荐编辑器（RecommendationEditorScreen）

- **功能**：在生成的一周推荐基础上，查看/编辑每日每餐；解决冲突（若有）；确认后写回计划。
- **UI**：周计划列表/表格展示，可改某餐食谱；冲突时弹出 ConflictResolutionDialog（选保留云端/本地等）；确认保存后返回计划列表。

## 六、食谱模块

### 6.1 食谱列表（RecipesListScreen）

- **功能**：搜索（名称/食材）；按月龄筛选（全部、6–8、8–12、12–24 个月）；按分类筛选（全部、主食、蔬菜、水果、蛋白质）；点击进详情。
- **UI**
  - 顶部：搜索框（带清除）。
  - 月龄：横向 FilterChip 组。
  - 分类：横向 FilterChip 组。
  - 下方：食谱卡片列表（图、名称、月龄、分类、安全/补铁等标签）。
- **状态**：加载中、空结果、错误。

### 6.2 食谱详情（RecipeDetailScreen）

- **功能**：查看食谱完整信息；营养与安全提示；份数调节；收藏/加入购物车等（若有）；过敏/安全/质地提示。
- **UI**（可折叠/展开区块）：
  - 封面图、食谱名、月龄、分类。
  - 安全风险标签（SafetyWarningBadge）、补铁标签（IronRichBadge）、质地提示（TextureWarning）、原味优先等。
  - 食材列表、制作步骤。
  - 营养成分（热量/蛋白质/钙/铁等）、营养等级与亮点。
  - 新鲜度与储存建议（FreshnessTipCard）、制作方式建议（CookingMethodBadge）。
  - 份数滑块；可展开的「处理建议」弹窗（HandlingAdviceDialog）。
- **状态**：加载中、加载失败、无数据。

### 6.3 食谱表单（RecipeFormScreen）

- **功能**：新增/编辑食谱（名称、月龄、分类、食材、步骤、营养等）。
- **UI**：多区块表单 + 保存/取消；食材与步骤可动态增删。

## 七、仓库模块

### 7.1 仓库列表（InventoryListScreen）

- **功能**：搜索食材；按保质状态（全部/即将过期/已过期等）、储存方式筛选；卡片列表展示；编辑/删除；添加。
- **UI**：搜索框、筛选 Chips、卡片列表（名称、图片、保质状态、储存方式等）；底部 FAB「添加」；删除确认对话框。

### 7.2 仓库物品表单（InventoryFormScreen）

- **功能**：新增/编辑库存物品（名称、数量、保质期、储存方式等）；可选支持扫码/识别（如 Scan 入口）。
- **UI**：表单字段 + 保存/返回。

---

## 八、体检与生长

### 8.1 体检记录列表（HealthRecordListScreen）

- **功能**：按宝宝展示体检记录列表；筛选「显示过期记录」；添加记录。
- **UI**：顶部 Switch「显示过期记录」；卡片列表（日期、体重、身高、头围、铁、钙、血红蛋白、AI 分析摘要、有效期）；过期项视觉区分（如灰色+「已过期」标签）；底部 FAB「添加」。

### 8.2 体检记录表单（HealthRecordFormScreen）

- **功能**：新增/编辑单条体检记录（日期、体重、身高、头围、铁、钙、血红蛋白等、备注、AI 分析触发）。
- **UI**：表单 + 保存/返回。

### 8.3 生长曲线（GrowthCurveScreen）

- **功能**：切换曲线类型（体重/身高/头围）；查看生长曲线图与标准参考（如 P3/P50/P97）；查看生长记录列表。
- **UI**
  - 顶部 FilterChip：体重、身高、头围。
  - 曲线图卡片（GrowthChart）：横轴时间，纵轴数值，标准线 + 实际数据点。
  - 图例：P3、P50、P97、实际数据。
  - 无数据时提示「添加体检记录后数据将显示在图表中」。
  - 下方生长记录列表（日期 + 体重/身高/头围）。

## 九、个人设置与用户

### 9.1 个人设置（SettingsScreen）

- **功能**：查看/编辑头像、昵称；修改密码；主题切换；退出登录。
- **UI**：iOS 风格分组列表。
  - 用户卡片：头像（可点换头像）、昵称（可点编辑）。
  - 账号安全：修改密码（带箭头）。
  - 偏好设置：主题等。
  - 底部「退出登录」按钮。
- **状态**：未登录提示、加载中、操作结果 Snackbar。

### 9.2 修改昵称（EditNicknameScreen）

- **功能**：单字段编辑昵称并保存。
- **UI**：输入框 + 保存/返回。

### 9.3 修改密码（ChangePasswordScreen）

- **功能**：原密码 + 新密码 + 确认新密码。
- **UI**：表单 + 提交/返回。

### 9.4 头像选择（AvatarPickerScreen）

- **功能**：从预设或相册选择头像。
- **UI**：头像网格或选择器 + 确认/返回。

## 十、AI 相关

### 10.1 AI 设置（AiSettingsScreen）

- **功能**：总开关「AI 功能」；策略选择：本地分析 / 远程分析 / 混合分析（带简短说明）。
- **UI**：卡片列表，开关 + 单选组 + 策略说明卡片。

### 10.2 AI 推荐（RecommendationScreen）

- **功能**：选择宝宝；填写可用食材（可选）、「只使用当前食材」开关；设置约束（每周最多鱼/蛋次数、早餐复杂度、每日最多餐数）；生成推荐；展示一周计划与营养摘要。
- **UI**
  - 宝宝下拉选择。
  - 可用食材多行输入 + Switch「只使用当前食材」。
  - 约束卡片（只读展示当前约束）。
  - 「生成推荐」按钮（加载中显示 loading）。
  - 错误时错误卡片。
  - 结果：营养摘要卡片、警告列表、每日计划卡片（日期 + 每餐食谱名、儿童话术、营养说明）。

## 十二、通用组件与状态

### 12.1 通用

- **EmptyState**：图标 + 标题 + 描述文案，用于无数据、未选宝宝等。
- **Loading**：全屏或区块内 CircularProgressIndicator。
- **错误**：Snackbar 或 ErrorDialog（标题 + 内容 + 确定）。

### 12.2 弹窗汇总

| 弹窗 | 用途 |
|------|------|
| RecipeSelectorDialog | 为某餐段选择食谱 |
| MealTimePickerDialog | 选择用餐时间 |
| NutritionGoalEditDialog | 编辑营养目标 |
| MealFeedbackDialog | 进食反馈（选项 + 过敏食材勾选） |
| DateRangePickerDialog | 选择计划日期范围（AI 推荐） |
| ConflictResolutionDialog | 计划冲突时选择保留方案 |
| HandlingAdviceDialog | 食谱处理/安全建议 |
| StorageSafetyDialog | 储存安全提示 |
| 删除确认 AlertDialog | 仓库物品等删除二次确认 |

### 12.3 设计约束

- **无页面级标题栏与返回按钮**：主框架不提供统一标题栏，子页若需返回需自行在页内提供。
- **底部导航仅主 5 个 Tab**：首页、食谱、扫描、计划、宝宝；子页不显示底部 Tab。
- **主色与圆角**：与现有 Material 3 主题一致；底部栏圆角、卡片圆角等见现有实现。
- **文案**：中文为主；关键操作、空状态、错误提示需预留文案位置。
